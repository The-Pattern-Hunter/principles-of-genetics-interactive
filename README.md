# Principles of Genetics — Interactive Companion

Author: Alok Patel

This repository hosts interactive Jupyter/Colab notebooks and datasets that accompany the book
**Principles of Genetics: An Interactive Learning Approach**.

## Repo structure
- `notebooks/` — Colab-ready notebooks (Unit-wise)
- `data/` — sample datasets (CSV, FASTA)
- `figures/` — minimal figures used in notebooks
- `teacher_resources/` — lesson plans, quizzes, slides
